Connecting your real Gate.io account

{% if configured %}

A read-only key is set. New trades, deposits and withdrawals are imported every 5 minutes; older history is fetched backwards, 30 days per request, until the account's history start date. Balances are checked once a day.

{% else %}

No read-only key yet. QF-gate's own bots, paper trading and cascades are recorded without one.

{% endif %}
  1. On Gate.io: API Management → create a key with read-only permission for Spot and Wallet. No trading, no withdrawals. Restrict it to your IP if you can.
  2. Put it in the .env file next to manage.py: GATE_READ_API_KEY=... and GATE_READ_API_SECRET=..., then restart the web server and the worker.
  3. Optional: on the Gate.io account's Edit page, set History start to when you opened the account, so the first import doesn't walk further back than needed.
  4. Click Sync now, then Check balances once the history shows complete.

Gate.io only returns 30 days of history per request and keeps the last 7 days by default, so the first import walks back window by window. Once imported, rows stay here for good. Every row keeps Gate.io's own id, so a re-import never doubles anything. Earn, convert, airdrops and transfers to futures are not imported: the balance check shows them as differences, and you can record each as an adjustment.
